# TagData 로드 가이드

## 📋 개요

2~5월 데이터를 포함한 모든 TagData를 효율적으로 로드하기 위한 체계적인 가이드입니다.

## 🛠️ 새로운 데이터 로드 시스템

### 기존 방식의 문제점
- ❌ 수동적인 CSV 변환 과정
- ❌ SQLite import 명령어 직접 사용
- ❌ 일관성 없는 프로세스
- ❌ 에러 처리 부족

### 새로운 시스템의 장점
- ✅ **자동화된 프로세스**: 한 번의 명령으로 완료
- ✅ **중복 데이터 처리**: 기존 데이터 자동 감지 및 처리
- ✅ **진행률 모니터링**: 실시간 로드 상태 확인
- ✅ **에러 복구**: 실패 시 롤백 및 재시도
- ✅ **데이터 검증**: 로드 전/후 데이터 무결성 확인

## 🚀 사용법

### 1. 현재 상태 확인
```bash

python scripts/data_loader.py --status
```

### 2. Excel 파일 직접 로드 (🆕 신규 기능!)
```bash
# 🎯 가장 간단한 방법: Excel → Pickle → DB 한 번에!
python scripts/data_loader.py --load-excel data/raw/tag_data_202502.xlsx

# 기존 데이터 덮어쓰기
python scripts/data_loader.py --load-excel data/raw/tag_data_202502.xlsx --replace

# Pickle 파일 저장 안 함 (DB만 바로 저장)
python scripts/data_loader.py --load-excel data/raw/tag_data_202502.xlsx --no-pickle

# 파일명만으로도 가능 (data/raw 폴더에서 자동 찾기)
python scripts/data_loader.py --load-excel tag_data_202502.xlsx
```

### 3. Pickle 파일 로드 (기존 방식)
```bash
# 최신 pickle 파일 자동 로드
python scripts/data_loader.py --load-latest

# 특정 파일명으로 로드
python scripts/data_loader.py --load-file tag_data_v20250215_120000.pkl.gz

# 덮어쓰기 옵션과 함께
python scripts/data_loader.py --load-latest --replace
```

## 📅 2~5월 데이터 로드 절차 (✨ 완전 간소화!)

### 🎯 초간단 절차 (Excel 파일만 있으면 끝!)

#### 1단계: Excel 파일 배치
```bash
# 새로운 Excel 파일을 data/raw/ 폴더에 배치
cp /path/to/tag_data_202502.xlsx data/raw/
cp /path/to/tag_data_202503.xlsx data/raw/
cp /path/to/tag_data_202504.xlsx data/raw/
cp /path/to/tag_data_202505.xlsx data/raw/
```

#### 2단계: 각 월별 로드 실행
```bash
# 🚀 한 줄로 끝! (Excel → Pickle → DB 자동 처리)
python scripts/data_loader.py --load-excel tag_data_202502.xlsx
python scripts/data_loader.py --load-excel tag_data_202503.xlsx  
python scripts/data_loader.py --load-excel tag_data_202504.xlsx
python scripts/data_loader.py --load-excel tag_data_202505.xlsx

# 또는 기존 데이터 교체가 필요한 경우
python scripts/data_loader.py --load-excel tag_data_202502.xlsx --replace
```

#### 3단계: 최종 확인
```bash
# 모든 데이터 로드 완료 후 상태 확인
python scripts/data_loader.py --status

# 예상 결과: 202501, 202502, 202503, 202504, 202505, 202506 모든 월 데이터 완료!
```


## ⚡ 성능 및 최적화

### 로드 속도
- **1월 데이터 (157만건)**: 약 2-3분
- **예상 2~5월 각각**: 비슷한 크기라면 각각 2-3분
- **전체 6개월**: 총 15-20분 예상

### 메모리 사용량
- **배치 크기**: 5,000건씩 처리
- **메모리 효율성**: 전체 데이터를 메모리에 한번에 로드하지 않음
- **안전한 처리**: 중간에 실패해도 이미 처리된 배치는 보존

### 디스크 공간
- **Pickle 파일**: 월별 약 20MB
- **SQLite DB**: 월별 약 200MB 증가 예상
- **임시 공간**: 로드 중 추가 공간 불필요

## 🛡️ 안전 기능

### 데이터 무결성
- **로드 전 검증**: pickle 파일 내용 분석
- **중복 방지**: 기존 데이터 자동 감지
- **트랜잭션**: 실패 시 자동 롤백
- **로드 후 검증**: 예상 건수와 실제 로드 건수 비교

## 📊 모니터링 및 확인

### 로드 진행상황 모니터링
```bash
# 로드 중 다른 터미널에서 실시간 확인
watch -n 5 "sqlite3 data/sambio_human.db 'SELECT COUNT(*) FROM tag_data'"
```

### 상세 검증 쿼리
```sql
-- 월별 상세 통계
SELECT 
    SUBSTR(CAST(ENTE_DT AS TEXT), 1, 6) as year_month,
    COUNT(*) as count,
    MIN(ENTE_DT) as first_date,
    MAX(ENTE_DT) as last_date,
    COUNT(DISTINCT 사번) as unique_employees
FROM tag_data 
GROUP BY SUBSTR(CAST(ENTE_DT AS TEXT), 1, 6)
ORDER BY year_month;

-- 일별 데이터 분포 확인
SELECT 
    ENTE_DT,
    COUNT(*) as count
FROM tag_data 
WHERE ENTE_DT >= 20250201 AND ENTE_DT <= 20250229
GROUP BY ENTE_DT
ORDER BY ENTE_DT;
```

## 🔧 문제 해결

### 자주 발생하는 문제

#### Q: "파일을 찾을 수 없습니다" 오류
```bash
# 해결: pickle 파일 경로 확인
ls -la data/pickles/tag_data_*.pkl.gz
python scripts/data_loader.py --status
```

#### Q: "기존 데이터가 있습니다" 경고
```bash
# 해결: --replace 옵션 사용 또는 기존 데이터 수동 삭제
python scripts/data_loader.py --load-latest --replace
```

#### Q: 로드 중 메모리 부족
```bash
# 해결: 배치 크기 축소 (data_loader.py 에서 batch_size 수정)
# 기본값: 5000 → 1000으로 변경
```

#### Q: DB 파일 잠김 오류
```bash
# 해결: Streamlit 앱 종료 후 재시도
pkill -f streamlit
python scripts/data_loader.py --load-latest
```
